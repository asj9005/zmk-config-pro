# ESB 입력 안정성 보완

이 변경은 키가 늦게 해제되거나 연결이 멈출 수 있는 소프트웨어 경로를 줄인다.
실제 사용 중 관측한 모든 끊김의 원인이 확인되었다는 의미는 아니다.

| 구간 | 변경 | 남는 한계 |
| --- | --- | --- |
| 무선 송신 | nRF52840에서 늦어진 ACK 설정을 감지해 기존 유한 재시도로 복귀한다. FIFO 데이터와 PID를 보존한다. | 전파 간섭·배터리·하드웨어 결함을 제거하지 않는다. |
| 동글 수신 | 양쪽 패킷을 도착 순서의 공통 FIFO에 넣고, 작업당 최대 8프레임을 처리한다. 패킷 경계와 키 위치 범위를 검증한다. | 무선 전송 전에 발생한 양손 입력의 물리적 시간 순서는 복원하지 않는다. |
| 스캔 | 큐를 16→32로 늘리고, 포화 시 저장한 최신 키 상태를 기존 큐 처리 뒤에 대조해 복구한다. | 포화 중에 눌렀다가 뗀 완전한 탭은 복원할 수 없다. |
| 탭·홀드 | 캡처 포화 시 대기 중 동작을 탭으로 확정하고, 오래된 이벤트부터 처리한다. 재생 데이터는 복사하며 불필요한 10ms 대기를 없앤다. | 과부하 시 원래 원했던 홀드 대신 탭이 나올 수 있다. |
| USB | 보고서를 복사해 순서대로 전송하고, 바쁜 endpoint나 일시적 실패에는 같은 보고서를 재시도한다. 최종 해제 상태를 별도로 보존한다. | 큐가 가득 차면 중간 탭이 빠질 수 있다. 복구용 마우스 보고서는 이전 상대 이동을 반복하지 않는다. |

공통 RX 저장 공간은 이전과 같고, 패킷마다 내부 메타데이터 6바이트를 추가한다.
각 pipe의 사용량 제한을 유지해 한쪽이 전체 공간을 독점하지 않게 한다.
암호 처리와 키 동작 실행 중에는 RX spinlock을 잡지 않는다.

USB 전송 버퍼는 IN 완료 또는 명시적인 RESET/DISCONNECTED로 전송이 중단될
때까지 유지한다. BOOT/REPORT 변경 시 대기 큐를 비우고 현재 상태를 새 형식으로
생성하지만, 이미 제출된 보고서 하나는 완료까지 남는다. nrfx 내부 이벤트 큐
포화로 앱에 알리지 않고 드라이버가 재초기화되는 경우는 이번 복구의 보장 범위
밖이다. 사용 중일 수 있는 DMA 버퍼를 덮어쓰는 타임아웃 우회는 사용하지 않는다.

스캔 복구는 Totem의 단일 physical layout을 대상으로 한다. 다른 layout으로
전환하는 펌웨어가 이 구현을 그대로 사용하지 않도록 빌드 시 단일 layout을 검사한다.
일반 키맵의 Base/Mouse/Nav 레이어 전환과 ZMK Studio 키 배치는 유지된다.

## 입력 설정

- Base E/R: 기존 `tap-preferred`, 200ms, `hold-while-undecided` 없음.
- Mouse E/R: `tap-preferred`, 180ms, `hold-while-undecided` 사용.
- 관련 콤보: 기존 50ms.
- 일반 마우스 곡선: 900ms, 후반 최대 4500 유지.
- E 고정 속도: 15750→7875. R 고정 속도: 562.5→450.
- RF: 기존 +8dBm, 2Mbps, 고정 채널 2 유지. 채널은
  `CONFIG_TOTEM_ESB_FIXED_CHANNEL`로 지정할 수 있지만 세 장치가 일치해야 한다.
- 기존에 실물 부팅을 확인한 주변 장치의 낮은 우선순위 초기화와 3초 지연을 유지한다.
  이번 연결 안정성 변경과 부팅 지연 제거를 함께 시험하지 않는다.
- 딥슬립은 배터리로 동작하는 좌우에만 적용하고 동글은 끈다.

## 검증과 진단

호스트 회귀 시험은 실제 C 함수에 큐·타이머·USB 장치의 결정적인 대체 구현을
연결한다. 포화, 버퍼 수명, 재시도, 해제, 이벤트 순서를 검사하며, 결함을 다시
넣었을 때 실패하는지도 확인한다. 이 시험은 Zephyr 스케줄링이나 무선 하드웨어를
에뮬레이션하지 않는다. ARM 컴파일·링크와 최종 설정 검사는 별도로 수행한다.

진단에는 RX 포화/최대 대기 시간, 스캔 포화/복구, 탭·홀드 포화,
USB 재시도/포화/최대 큐 깊이, 늦은 ACK 설정 횟수를 추가한다.
키 내용이나 개인키는 출력하지 않는다. 고정 크기 큐를 크게 잡은 것만으로
포화가 없어졌다고 판단하지 않는다.

업로드 후에는 양손 빠른 타이핑, 방향키 해제, 이동 중 Base 복귀,
Alt-Tab 해제, 좌우 전원 및 동글 USB 재연결을 확인한다.
한쪽이 다시 멈추면 전원을 껐다 켜기 전에 USB 로그로 송신 완료 수와
무선 상태·위 카운터를 함께 수집한다.
